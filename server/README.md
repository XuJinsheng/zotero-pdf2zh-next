# zotero-pdf2zh-next

Local Python server for the Zotero `zotero-pdf2zh-next` plugin.

Install and run with uv:

```bash
uv tool install --python 3.13 zotero-pdf2zh-next
zotero-pdf2zh-next
```

The default service URL is:

```text
http://127.0.0.1:8890
```
